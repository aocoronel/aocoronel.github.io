A program that fetches jokes from [Joke API](https://github.com/15Dkatz/official_joke_api), and displays them using `cowsay`.

```console
 ____________________________________
< What kind of pants do ghosts wear? >
 ____________
< Boo jeans. >
 ------------
         \   ^__^
          \  (^^)\_______
             (__)\       )\/\
                ||----w |
                ||     ||

```

## Using

```bash
odin run .
```
